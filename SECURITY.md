# Security Policy

## Supported Versions

Security fixes are intended for the current `1.x` release line.

## Reporting A Vulnerability

Please report security issues privately through GitHub Security Advisories for `byteface/domonic` where possible:

https://github.com/byteface/domonic/security/advisories/new

If that is not available, email `byteface@gmail.com` with a minimal reproduction and the affected version. Please avoid opening public issues for undisclosed vulnerabilities.

## Scope

domonic intentionally includes compatibility APIs for generating markup, parsing documents, launching local project scaffolds, and mirroring browser or JavaScript behavior. Reports are most useful when they identify an exploitable path in normal library use rather than intentional local developer tooling.
