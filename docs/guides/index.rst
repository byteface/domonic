Guides
======

.. meta::
   :description: Practical domonic guides for Python HTML generation, web scraping, BeautifulSlop, server-side rendering, live DOM updates, parser performance, CSS selectors and XPath.
   :keywords: domonic guide, Python HTML guide, Python web scraping guide, BeautifulSlop tutorial, Python server-side rendering, DOM patch guide

These guides are written around jobs people actually want to do with domonic.
They are short, copy-paste friendly, and link back into the deeper package
reference when you need the full API.

They also double as a Python-friendly route into the web platform. The examples
use real HTML tags, browser DOM method names, CSS selectors, XPath expressions,
and JavaScript-style helpers, so the snippets are useful both for shipping code
and for learning the vocabulary of browser development.

They are also useful in the opposite direction: JavaScript developers can use
domonic as a softer landing in Python because the examples keep familiar
browser concepts visible instead of hiding them behind a Python-only abstraction.
